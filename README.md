# 指法小達人（網站版）

英打指法與小鶴雙拼／音形練習。用瀏覽器開啟即可使用，**所有練習紀錄只存在您的瀏覽器裡**，本網站不接收、不保存任何資料。

## iPad 使用方式

1. 用 Safari 開啟本網站。
2. 點分享按鈕 →「加入主畫面」。之後從主畫面圖示開啟，離線也能使用。
3. 接上實體鍵盤再開始練習。
4. 定期在「設定與備份」頁按「匯出備份檔」，存到「檔案」App。
